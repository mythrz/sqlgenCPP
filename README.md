# FAQ

**Is this an official project of sqlgen or O3DE?**

No. This is not part of [sqlgen](https://github.com/munich-data-engineering/sqlgen) or [O3DE](https://github.com/o3de/o3de/) official/approved teams/projects. If you have any questions regarding that project, please adress them in their respective repo.

**Why not name the gem sqlgen?**

To avoid CMake name collisions between the gem and the submodule; there are a few changes in [CodeFirstCppDB_sqlgen](https://github.com/mythrz/CodeFirstCppDB_sqlgen).
